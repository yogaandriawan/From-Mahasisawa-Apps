# Screenshots bukti praktikum

File wajib dibuat dari aplikasi yang **benar-benar berjalan** pada emulator/perangkat Android.

1. `sebelum-input.png` — Semua input kosong, tombol Simpan Profil nonaktif dan kartu profil belum diisi.
2. `sesudah-input.png` — Input terisi valid, tombol sudah ditekan, kartu profil menampilkan data tersimpan.

Buka project dengan Android Studio, jalankan emulator, lalu gunakan tombol **Take Screenshot** di Running Devices. Jangan mengganti bukti praktikum dengan mockup atau Android Studio Compose Preview.
